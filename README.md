# Novatech-Devops

##Objetivo
La empresa tecnológica peruana Comercial NovaTech S.A.C. opera un ecosistema tecnológico conformado por un portal web de e-commerce y aplicaciones internas: inventario, despachos y reportes comerciales. El presente proyecto incorpora validación de código, scripts de despliegue, empaquetado de dependencias + servidor web y automatización del ciclo de vida para solucionar los problemas de DevOps de la empresa.

##Tecnologías
- Repositorio: GitHub
- CI/ID: GitHub Actions
- Contenedores: Docker
- Registro de Imágenes: Almacenamiento Local
- Automatización: Bash Script
- Entorno de PoC: entorno Local y GitHub Runners
